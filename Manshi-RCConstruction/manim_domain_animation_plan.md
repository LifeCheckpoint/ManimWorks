# ManimGL 域性质动画计划

## 动画目标
演示域的性质，特别是从有理数域 Q 扩展到 Q(√2) 的过程，通过在一个矩形框中取出、计算并放回元素的方式展示域的封闭性。

## 动画细节需求
*   初始矩形框显示 5 个随机有理数。
*   随机选择两个有理数进行加法和乘法演示。
*   显示加法和乘法的结果，并将结果放回框中。
*   第二个矩形框（Q(√2)）显示 a+b√2 形式的数，其中 a, b 为小整数。
*   颜色要求：普通有理数和有理数系数用红色，无理数系数用绿色，$\sqrt{2}$ 用白色。

## 动画计划步骤

1.  **场景初始化：**
    *   设置 Manim 场景。
    *   定义颜色常量：红色用于有理数和有理数系数，绿色用于无理数系数，白色用于 $\sqrt{2}$。

2.  **创建有理数域 (Q) 演示部分：**
    *   绘制一个矩形框作为容器。
    *   在矩形框上方添加标题 "a \in Q"。
    *   在框内生��并显示 5 个随机的有理数（使用红色）。

3.  **演示 Q 的加法封闭性：**
    *   从框中随机选择两个有理数，并将它们移出框外。
    *   显示这两个数的加法算式。
    *   计算结果并显示。
    *   将结果移回矩形框中。

4.  **演示 Q 的乘法封闭性：**
    *   从框中随机选择两个有理数（可以与之前不同），并将它们移出框外。
    *   显示这两个数的乘法算式。
    *   计算结果并显示。
    *   将结果移回矩形框中。

5.  **过渡到扩域 (Q(√2)) 演示部分：**
    *   清空矩形框内的有理数。
    *   修改矩形框的标题为 "a+b\sqrt{2} \in Q(\sqrt{2})"。
    *   在框内生成并显示 a+b$\sqrt{2}$ 形式的数，其中 a, b 为小整数（a, b 用红色，$\sqrt{2}$ 用白色）。

6.  **演示 Q(√2) 的加法封闭性：**
    *   从框中随机选择两个 a+b$\sqrt{2}$ 形式的数，并将它们移出框外。
    *   显示这两个数的加法算式。
    *   计算结果并显示（a, b 用红色，$\sqrt{2}$ 用白色）。
    *   将结果移回矩形框中。

7.  **演示 Q(√2) 的乘法封闭性：**
    *   从框中随机选择两个 a+b$\sqrt{2}$ 形式的数（可以与��前不同），并将它们移出框外。
    *   显示这两个数的乘法算式。
    *   计算结果并显示（a, b 用红色，$\sqrt{2}$ 用白色）。
    *   将结果移回矩形框中。
